---

## 💡 问题根源

根据README文档，XRoboToolkit PC Service的架构是：

```
Pico头显 ──→ RoboticsServiceProcess (监听端口) ──→ PXREARobotSDK (gRPC Client)
                     ↓
           检测到 "TestDevice" (模拟设备)
```

**"TestDevice"出现的原因**：
1. Pico头显未正确连接到RoboticsServiceProcess
2. RoboticsServiceProcess没有检测到真实的Pico设备
3. SDK自动使用测试设备作为fallback

## 📚 关键文档参考

### 设备连接协议（从README）

```
TCP/UDP通信协议:
- 服务器命令协议（设备控制、数据传输）
- 客户端消息协议（连接、状态、数据传输）
```

### 回调类型（从README）

```c
PXREADeviceFind     = 1<<4,   // 设备上线
PXREADeviceMissing  = 1<<5,   // 设备下线
PXREADeviceConnect  = 1<<9,   // 设备连接
```

当真实设备连接时，应该收到`PXREADeviceFind`回调。
