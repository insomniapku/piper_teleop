# Pico遥控机械臂 - 使用技巧和调优指南

## 🎮 为什么感觉不灵敏？

### 原因1: Delta映射机制
当前系统使用**相对运动映射**，不是绝对位置映射：
- ✓ 好处：避免突然跳变，更安全
- ⚠️ 缺点：需要理解"参考点"的概念

### 原因2: 安全限制
代码中有多重保护：
- 最大单步移动限制：5cm
- 工作空间边界裁剪
- 位置缩放系数：2.0（控制器移动1cm → 机械臂移动2cm）

---

## 💡 正确的使用方法

### 关键概念：参考点系统

每次握住握把时，系统会设置一个**参考点**：
```
[引用设置] XR: [0.294, -0.214, 0.199], EE: [0.145, -0.000, 0.194]
          ↑ 控制器当前位置              ↑ 机械臂当前位置
```

**之后的所有移动都是相对于这个参考点的！**

## 📖 使用步骤详解

### 步骤1: 启动并初始化
```bash
python3 pico_teleop_piper.py
```
等待显示"✓ 准备就绪"和"开始遥操作"

### 步骤2: 握住握把（重要！）
- 握住右手控制器的**侧面握把**（不是扳机）
- 握力要超过50%
- 看到 `[引用设置]` 消息

### 步骤3: 理解参考点
设置参考点后：
- 控制器向前移动 → 机械臂向前（X+）
- 控制器向右移动 → 机械臂向右（Y+）
- 控制器向上移动 → 机械臂向上（Z+）

**关键**：移动量是相对的，不是绝对的！

### 步骤4: 开始移动
- **缓慢**移动控制器
- 每次移动5-10厘米
- 观察机械臂响应

### 步骤5: 重新校准
如果感觉不对：
- 松开握把（系统暂停）
- 重新握住握把（重新设置参考点）
- 继续控制

## ⚙️ 提高灵敏度 - 3种方法

### 方法1: 提高缩放系数（推荐）

编辑 `pico_teleop_piper.py`：
```python
# 第108行附近
self.position_scale = 2.0  # 改为 3.0 或 4.0
```

**效果对比**：
- `1.0` - 控制器移动10cm，机械臂移动10cm（1:1）
- `2.0` - 控制器移动10cm，机械臂移动20cm（默认）
- `3.0` - 控制器移动10cm，机械臂移动30cm（更灵敏）
- `5.0` - 控制器移动10cm，机械臂移动50cm（非常灵敏）

**建议**：先试试 `3.0`

---

### 方法2: 增加最大移动速度

```python
# 第109行附近
self.max_delta = 0.05  # 改为 0.08 或 0.10
```

**说明**：
- 这是单步最大移动距离（米）
- 值越大，机械臂响应越快
- 但太大可能导致突然跳变

**建议**：先试试 `0.08`

---

### 方法3: 降低控制频率（如果卡顿）

```python
# 第248行附近
time.sleep(0.01)  # 100Hz，改为 0.02 (50Hz) 如果系统卡顿
```

## 🎯 实战技巧

### 技巧1: 正确的握持姿势
```
握把位置：控制器侧面，食指下方
✓ 正确：侧面握紧
✗ 错误：只按扳机（那是夹爪控制）
```

### 技巧2: 分段移动
不要试图一次性移动到目标：
```
❌ 错误：控制器大幅移动 → 机械臂到达边界 → 停止响应
✓ 正确：移动10cm → 观察 → 松开握把 → 重新握住 → 继续移动
```

### 技巧3: 利用参考点重置
```
1. 机械臂在位置A
2. 握把 → 参考点设为A
3. 移动控制器 → 机械臂到B
4. 松开握把
5. 重新握把 → 参考点设为B（新的起点）
6. 继续移动
```

### 技巧4: 控制器位置管理
```
避免：控制器移动到身体后方或极限位置
建议：保持控制器在舒适的前方活动范围
```

## 🚨 常见问题

### Q1: 握住握把，但机械臂不动
**检查**：
1. 是否看到 `[引用设置]` 消息？
2. 控制器握把是否真的握紧？（握力>50%）
3. 运行 `python3 diagnose_xr_connection.py` 检查握把值

### Q2: 机械臂移动一点就停了
**原因**：到达工作空间边界
**解决**：
1. 松开握把
2. 把控制器移回中心区域
3. 重新握住继续

### Q3: 移动方向不对
**原因**：坐标系理解问题
**尝试**：
- X轴：机械臂前后
- Y轴：机械臂左右
- Z轴：机械臂上下

### Q4: 响应延迟
**检查**：
1. WiFi信号强度
2. PC性能（`top` 命令查看CPU）
3. 降低控制频率（time.sleep改为0.02）

## 📝 总结

### 最重要的3点：
1. **理解参考点机制** - 每次握把都会重置参考点
2. **提高position_scale** - 从2.0改到3.5-5.0
3. **分段移动** - 不要期望一次性移动很远

### 推荐工作流程：
```
1. 启动程序
2. 握住握把（设置参考点）
3. 缓慢移动控制器5-10cm
4. 观察机械臂响应
5. 松开握把
6. 调整控制器位置到舒适区
7. 重新握住（新参考点）
8. 重复3-7
```
