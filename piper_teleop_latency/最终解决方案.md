## 🚀 完整安装步骤

### 第一步：准备Pico头显（约5分钟）

#### 1.1 启用开发者模式
```
戴上Pico头显 → 设置 → 系统 → 关于 → 连续点击"版本号"7次
```
会提示"您已进入开发者模式"

#### 1.2 启用USB调试
```
设置 → 系统 → 开发者选项 → 打开"USB调试"
```

#### 1.3 连接USB
- 用USB-C数据线连接Pico头显到PC
- 头显内会弹出"允许USB调试"的提示
- **点击"允许"** ✓

---

### 第二步：安装XRoboToolkit应用（约2分钟）

#### 2.1 运行安装脚本
```bash
cd /home/zktitan/lcz0820
bash install_pico_app.sh
```

**脚本会自动**：
- ✓ 检查APK文件
- ✓ 检查ADB连接
- ✓ 卸载旧版本（如果有）
- ✓ 安装新版本
- ✓ 显示配置说明

#### 2.2 手动安装（备选方案）
如果脚本失败，可以手动安装：
```bash
# 检查设备连接
adb devices

# 安装APK
adb install /home/zktitan/Downloads/XRoboToolkit-PICO-1.1.1.apk
```

---

### 第三步：在Pico中配置连接（约3分钟）

#### 3.1 启动应用
```
戴上Pico头显 → 应用库 → 查找"XRoboToolkit" → 启动
```

**注意**：应用可能在"未知来源"或"侧载应用"分类中

#### 3.2 配置连接参数
在XRoboToolkit应用界面中：
```
Server IP:  192.168.111.123    # PC的IP地址
Port:       60061              # 默认端口
```

#### 3.3 连接
点击"Connect"或"连接"按钮

**成功标志**：
- 应用显示"Connected"或"已连接"
- PC终端显示"device found: Pico 4"（不再是TestDevice）

## 🔧 故障排除

### 问题1: adb devices显示"unauthorized"

**原因**：未在头显中授权USB调试

**解决**：
1. 重新插拔USB
2. 在头显中查看是否有授权弹窗
3. 点击"允许"并勾选"总是允许"

---

### 问题2: 安装失败 "INSTALL_FAILED_UPDATE_INCOMPATIBLE"

**原因**：已有旧版本

**解决**：
```bash
adb uninstall com.pico.xrobotoolkit
adb install /home/zktitan/Downloads/XRoboToolkit-PICO-1.1.1.apk
```

---

### 问题3: 找不到应用

**检查**：
```bash
# 确认是否安装成功
adb shell pm list packages | grep xrobo
```

**在头显中**：
- 检查"未知来源"分类
- 检查"所有应用"列表
- 尝试在搜索框输入"XRobo"

---

### 问题4: 应用无法连接PC

**检查清单**：
```bash
# 1. PC和Pico在同一网络？
ping 192.168.111.85

# 2. RoboticsServiceProcess在运行？
ps aux | grep RoboticsServiceProcess

# 3. 防火墙阻止？
sudo ufw status
# 如果启用了防火墙，开放端口60061
sudo ufw allow 60061
```
