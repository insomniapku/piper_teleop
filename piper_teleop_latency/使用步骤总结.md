### 第四步：开始控制

#### 4.1 首次激活
1. **戴上Pico头显**
2. **握住右手控制器的握把**（握力要大于50%）
3. 看到提示：
   ```
   [引用设置] XR: [...], EE: [...]
   ```
4. 此时当前位置成为参考点

#### 4.2 移动控制
- **轻轻向前/后移动控制器** → 机械臂X轴移动
- **轻轻向左/右移动控制器** → 机械臂Y轴移动  
- **轻轻向上/下移动控制器** → 机械臂Z轴移动

**注意**：
- 首次使用建议小幅移动
- 控制器移动1cm，机械臂移动约2cm（可调整）
- 程序会自动限制在安全范围内

#### 4.3 夹爪控制
- **按下扳机** → 夹爪逐渐关闭
- **松开扳机** → 夹爪逐渐打开

#### 4.4 暂停和继续
- **松开握把** → 暂停控制，机械臂保持位置
- **重新握住** → 重新设定参考点，继续控制

#### 4.5 停止
- **按B按钮** → 紧急停止程序
- **Ctrl+C** → 正常退出

## 🔧 故障排除速查

### 问题1: "控制器位置全为0"

**症状**: 启动后XR数据显示 [0.000, 0.000, 0.000]

**解决**:
```bash
# 1. 检查PC Service
ps aux | grep XRobo

# 2. 确认USB连接
lsusb | grep -i pico

# 3. 重启流程
# - 关闭程序
# - 重启PC Service
# - 重新插拔Pico USB
# - 重新运行程序
```

---

### 问题2: "机械臂使能失败"

**症状**: 提示"无法使能机械臂"

**解决**:
```bash
# 1. 检查CAN接口
ifconfig | grep can0

# 2. 如果CAN未启动
cd piper_sdk/piper_sdk
bash can_activate.sh can0 1000000 "1-11.2:1.0"

# 3. 检查硬件
# - 机械臂电源是否打开
# - 急停按钮是否释放
# - CAN线连接是否牢固
```

---

### 问题3: "机械臂移动但不跟随控制器"

**可能原因**:
1. 握把没有握紧（握力需>50%）
2. 参考点未正确设置
3. position_scale设置过小

**解决**:
- 松开握把，重新握紧设置新参考点
- 尝试更大幅度移动控制器
- 增大 `position_scale` 参数

---

### 问题4: "机械臂移动过快或过慢"

**调整**:
- 过快: 减小 `position_scale` (如改为1.0)
- 过慢: 增大 `position_scale` (如改为3.0)
- 不平滑: 减小 `max_delta` (如改为0.02)

## ⚠️ 安全提醒

1. **首次使用**
   - 使用 `position_scale = 1.0` 开始
   - 缓慢、小幅移动控制器
   - 确保机械臂周围无障碍物

2. **操作中**
   - 随时准备按B按钮紧急停止
   - 不要突然大幅移动控制器
   - 注意工作空间边界

3. **异常情况**
   - 发现异常立即松开握把
   - 必要时按下机械臂急停按钮
   - Ctrl+C可正常退出程序
